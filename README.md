# SRM (1) Concept Landing Page

> *"Sound. In its finest form."*

> Interactive product concept web application built for the GDG on Campus SRM Technical Domain recruitment. Includes product hotspot nodes, adaptive dark-mode UI, and technical spec cards. Designed & prototyped at https://misty-embeds-539797.framer.app/

This repository contains my submission for the **Google Developer Groups on Campus SRM Recruitments 2026 – Technical Domain**.

## Project Overview
An interactive, dark-themed concept landing page designed for the "SRM (1)" wireless headphones. The page features a minimalist UI inspired by modern hardware design, interactive UI elements, and a clean spec breakdown.

## Features
- **Interactive Hotspots:** Tap or hover over nodes to reveal product details.
- **Color Customization:** Switch live between Cyber Black, Frosted, and Glacier finishes.
- **Tech Spec Highlights:** Responsive grid showcasing battery life (40 hrs), driver specs (40mm), and Adaptive ANC.
