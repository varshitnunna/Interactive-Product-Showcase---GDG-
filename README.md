## Project Overview

**SRM (1)** is a dark-themed concept product showcase designed for high-fidelity wireless headphones. Built entirely with Framer the experience centers around visual hierarchy precise spatial interactions and responsive product customization inspired by modern hardware design aesthetics.

## Key. Highlights

### 1. Interactive Hotspots

- Node-based hover and tap interactions positioned across the product canvas.
- Smoothly reveals feature callouts and component breakdowns without cluttering the main UI.

### 2. Live Product Variants

- **Cyber Black:** Matte finish with high-contrast metallic accents.
- **Frosted:** Semi-translucent shell highlighting acoustic architecture.
- **Glacier:** Clean reflection minimalist design.
- Features real-time asset switching with smooth fluid transitions.

### 3. High-Performance Tech Spec Grid

- responsive layout highlighting core specifications:
**Playback:** 40-hour continuous battery life.
**Acoustic Driver:** Custom-tuned 40mm dynamic drivers.
**Active Noise Cancellation:** Hybrid Adaptive ANC with transparency pass-through.

### 4. Modern Design System

- Clean typography hierarchy and balanced spacing.
- Optimized layout scales smoothly across desktop, tablet and mobile viewports.
